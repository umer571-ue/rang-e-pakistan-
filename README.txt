RANG-E-PAKISTAN WEBSITE
=======================

A responsive, static brand landing page for Rang-e-Pakistan.

HOW TO VIEW
1. Extract the ZIP.
2. Open index.html in any modern browser.
3. Internet connection is needed for Google Fonts; the website itself works without them.

FILES
- index.html: page content and sections
- styles.css: responsive visual design
- script.js: mobile navigation and current year

BEFORE PUBLISHING
- Replace hello@rangepakistan.example with your real business email in index.html.
- Add your real phone number, social links, ordering method and address if desired.
- The flavours shown are concepts/inspiration, not a claim that products are already available.
- Do not publish ingredient, nutrition, halal, certification, or shelf-life claims until verified.
- This is a static front-end site. It does not currently have a checkout, payment gateway, order database, or admin panel.

PUBLISHING
Upload the extracted files to any static website host, keeping index.html, styles.css and script.js in the same folder.
